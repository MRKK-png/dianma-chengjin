# 虚构教学项目：社区展览导览

本材料全部为教学构造，不对应真人作品或实际实施项目。

- 学习背景：空间设计；目标方向：交互设计。
- 项目问题：展览内容较多，参观者需要选择主题、了解路线、找到下一处展点。
- 原有材料：空间功能分区示意、路线草图、展点内容清单。
- 待验证的假设：按主题整理内容可能帮助参观者决定先看什么。
- 尚无证据：真实访谈、可用性测试、数字原型、实施效果。
- 本人贡献：教学例子不设真实作者；实际使用时必须由用户说明自己的贡献。

## 建议补充

1. 用信息架构图展示主题、路线和展点的层级。
2. 用低保真框架图展示路线选择页面。
3. 用交互流程图展示选择路线、查看展点和返回路线的路径。
4. 如条件允许，实际验证一项任务，记录真实发现；否则明确标记待验证。

任何计划中的内容都不能写成已经完成的研究或成果。
