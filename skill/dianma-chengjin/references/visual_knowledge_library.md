# 教学概念

| 概念 | 用途 | 必需元素 | 图例 |
|---|---|---|---|
| 信息架构 | 组织内容与导航 | 层级、分类依据、入口 | `../assets/information-architecture.svg` |
| 低保真框架 | 先确认页面结构 | 主任务、信息区域、操作入口 | `../assets/wireframe.svg` |
| 交互流程 | 展示任务怎么完成 | 起点、动作、判断、结果和返回 | `../assets/interaction-flow.svg` |
| 用户旅程 | 理解连续体验 | 阶段、任务、触点、困难、待验证项 | `../assets/user-journey.svg` |

图例为虚构教学示意。用户研究用于收集证据；可用性测试用于观察实际任务表现。不要凭图例生成真实研究结果。是否研究或测试、做到什么程度，依据问题、项目条件与岗位要求决定。
