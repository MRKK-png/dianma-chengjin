# 跨专业能力转译

这些是教学类比，不是已有能力的证明。每次转译都要找到原材料，并补上目标语境的证据。

| 原项目经验 | 可讨论的迁移方向 | 仍需证明 |
|---|---|---|
| 空间动线 | 任务路径与流程组织 | 数字页面的状态、操作和反馈 |
| 功能分区 | 信息层级 | 分类依据、导航和内容优先级 |
| 服务触点 | 用户旅程 | 受众、任务、触点间的真实关联 |
| 展陈叙事 | 内容与体验组织 | 内容选择依据与交互细节 |
| 视觉表达 | 信息可读性 | 层级、可访问性、不同屏幕适配 |

推荐表述：“原项目已有组织路径的经验；数字交互的错误状态和反馈仍需补充。”
