# 点马成金 · Dianma Chengjin

面向设计转行与求职场景的 AI Skill：从课程作业中发现设计脉络，诊断目标岗位的能力缺口，指导补充作品，再形成有策略的作品集表达。

**六步流程：整理材料 → 发现脉络 → 诊断缺口 → 指导补作品 → 匹配岗位 → 输出排版。**

本仓库是经过脱敏与内容改写的公开教学版。演示案例、岗位描述、人物和数据均为虚构，不对应真实学员、公司招聘要求或实际研究结果。没有招聘机构或专家本人背书。

## 包含什么

- `skill/dianma-chengjin/SKILL.md`：Skill 主定义。
- `skill/dianma-chengjin/scripts/`：六步 Markdown 指导手册，供 AI 阅读，不是可执行程序。
- `skill/dianma-chengjin/references/`：项目模板、能力转译、JD 解码、教学概念、排版及进度指南。
- `skill/dianma-chengjin/assets/`：重新绘制的通用 SVG 教学图例。
- `examples/`：虚构项目材料和虚构岗位 JD。
- `demo/index.html`：自包含的六步静态报告，下载后可离线打开。
- `skill/dianma-chengjin/test-prompts.json`：人工验收提示词与预期行为。

## 快速体验

1. 下载仓库 ZIP 并解压。
2. 双击 `demo/index.html`，查看静态示例报告；无需安装依赖或联网。
3. 若要重新分析自己的项目，需要能读取本地 Markdown Skill 的 AI 运行环境。把 `skill/dianma-chengjin/` 按该环境的用户级 Skill 安装规则放置，并让 AI 读取 `SKILL.md`。
4. 将 `examples/project.md` 和 `examples/job-description.md` 作为教学输入。真实求职时，换成经你授权处理的材料和当前有效的岗位原文。

此仓库没有内置 AI 模型、自动招聘接口或独立应用。静态 HTML 的离线查看不代表 AI 分析可以离线运行。不同 Skill 运行环境的安装与兼容性未在此次发布中实测。

## 使用边界

只依据用户提供的证据分析，不把空间设计经验直接认定为数字交互能力；补充图例和概念时注明教学建议。岗位判断应引用 JD 原文，推断必须显式标注。不要编造研究、奖项、任职经历或通过率。

默认输出 Markdown、SVG 或 HTML。若用户另行提供并授权连接排版工具，可在已有策略上排版；仓库本身不要求任何外部设计工具。
